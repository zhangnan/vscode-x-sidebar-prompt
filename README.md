# VS Code X 侧栏阅读模式 Prompt

一份中文完整任务 Prompt，用于描述如何把 VS Code 内置浏览器集成为左侧 X 阅读侧栏，以及插件、移动设备模拟和页面视觉处理分别负责什么。

**[打开完整 Prompt](./PROMPT.md)**

使用时将 PROMPT.md 的任务正文交给具备本机开发和验证能力的编码助手，并允许它先检查实际 VS Code 版本。

主要需求：

- 活动栏按需打开原生浏览器侧栏，无独立网页编辑器标签。
- 默认移动设备模拟，视口随侧栏尺寸变化。
- 使用编辑器字体、字号和注释色。
- 图片、视频、链接卡片及嵌套引用媒体默认同背景遮挡，悬停揭开。
- 移除头像专用列，隐藏 emoji、名字装饰徽标和悬浮发帖按钮。
- 广告整帖同背景遮挡，保留占位与原生列表机制。

## 状态与限制

这是需求与实施约束文档，**不是可直接安装的插件发行包**，也不保证某个补丁已适配所有 VS Code 或 X 版本。文档来自一次本地改造过程：侧栏和移动布局曾实际打开；嵌套媒体遮罩仍发生过遗漏，部分后续修补仅通过代码检查，未完成对应界面复验。完整验收清单保留在 Prompt 中。

内部浏览器接口可能随 VS Code 更新改变。修改安装目录可能触发完整性警告；不应关闭检查来隐藏警告。仓库不包含 VS Code 程序副本、Cookie、登录数据或个人配置。
